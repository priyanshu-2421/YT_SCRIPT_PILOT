# 🎬 YT_SCRIPT_PILOT – AI YouTube Script Generator

## 📌 About the Project

YT_SCRIPT_PILOT is an AI-powered YouTube script generation system built using Python and Google ADK. It uses multiple AI agents to generate research notes, organize video content, write scripts, and suggest YouTube titles and thumbnails.

## ✨ Features

* 🔍 **Research Agent:** Generates detailed research notes and interesting facts about a given topic.
* 📝 **Structure Agent:** Organizes content into an engaging video structure.
* 🎥 **Script Writer Agent:** Generates a conversational YouTube script with pauses, B-roll suggestions, and music cues.
* 🖼️ **Thumbnail Agent:** Suggests catchy titles, thumbnail ideas, descriptions, and hashtags.
* 🤖 **Sequential Workflow:** Coordinates multiple AI agents to complete the content creation process.

## 🛠️ Tech Stack

* Python
* Google Agent Development Kit (ADK)
* Groq API
* Llama 3.1 8B Instant
* LiteLLM
